# Overtake-probability model

_Generated by `npm run train:overtake` - do not edit by hand._

**Question:** Will the car directly behind pass the car ahead within 10s?

**Data:** 4 recorded F1 26 race(s), 56845 one-second samples of close battles (car directly behind, within 3s), 1845 of them followed by a pass (base rate 3.2%). Labels come from the game's own OVTK events; flashbacks are rewound out of the data.

**Model:** logistic regression, standardised features, L2-regularised, class-weighted with a prior correction so outputs are real probabilities. Written from scratch (`src/ml/logistic.js`) - no ML dependency.

## Held-out evaluation

Leave-one-race-out: each race is scored by a model trained only on the others.

| | AUC | Log loss | Brier | Brier skill |
|---|---|---|---|---|
| Model (9 features) | 0.851 | 0.116 | 0.029 | 0.091 |
| Baseline (log gap only) | 0.854 | 0.111 | 0.027 | 0.127 |

AUC: 0.5 is a coin flip, 1.0 is perfect ranking. Brier skill: improvement over always predicting the base rate.

## Caveats

- Small data: 4 race(s). Every new capture can be added - re-run `npm run train:overtake`.
- Mostly AI drivers, so it learns how the game's AI battles; the player is one car of 22.
- OVTK fires on any position swap, including some that come from a car ahead running wide or into the pits.
